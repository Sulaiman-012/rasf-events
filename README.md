# منصة مسابقات وفعاليات رصف

منصة داخلية لشركة **رصف للاستثمار** (مجموعة دام القابضة):
- **صفحة الموظفين**: يمسح الموظف رمز QR، يكتب اسمه مرة وحدة، ويجاوب على السؤال من جواله.
- **النتائج** مباشرة، وصفحة **«حسابي»** لكل موظف (نقاطه وترتيبه ورسائله).
- **لوحة الإدارة** (`/admin`): المسابقات والأسئلة والجدولة، مجموعات الشاشات، شاشات LG، استوديو الفعاليات، مكتبة الصور، اعتماد رسائل الموظفين، التحليلات، وتصدير Excel.
- **شاشات LG StanbyME الطولية**: لكل شاشة رابط سري خاص فيها، تعرض المسابقة (ويقدر الزائر يشارك باللمس) أو صورة الفعالية مع رمز QR والرسالة المعتمدة.

التشغيل **مجاني بالكامل** على Cloudflare (خطة Workers المجانية + قاعدة بيانات D1 المجانية). **ما تحتاج بطاقة ائتمان**، وما نستخدم أي خدمة مدفوعة.

---

## قبل ما تبدأ: جهّز ثلاث أشياء

1. **حساب Cloudflare مجاني**: سجّل من <https://dash.cloudflare.com/sign-up> بإيميل العمل.
2. **مفتاح الإعداد `SETUP_KEY`**: كلمة سر تستخدمها **مرة وحدة** لإنشاء حساب مالك المنصة. اخترها طويلة (مثلاً ٢٠ حرف) واحفظها عندك.
3. **مفتاح الجلسات `SESSION_SECRET`**: نص عشوائي طويل (٣٢ حرف أو أكثر، حروف وأرقام). ما تحتاج تحفظه أو تتذكره، بس لا تشاركه مع أحد.
   > طريقة سهلة: افتح <https://www.random.org/strings/?num=1&len=32&digits=on&upperalpha=on&loweralpha=on&format=html> وانسخ الناتج.

## الطريقة (أ) — الموصى بها: من GitHub عبر لوحة Cloudflare (بدون أوامر)

### ١) ارفع المشروع على GitHub
1. سجّل دخولك في <https://github.com> (أو أنشئ حساب مجاني).
2. اضغط **New repository**، سمّه مثلاً `rasf-events`، واختر **Private** (خاص).
3. اضغط **uploading an existing file**، واسحب **كل محتويات** مجلد المشروع (بعد فك ملف الـ zip)، ثم **Commit changes**.

### ٢) أنشئ قاعدة البيانات D1
1. في لوحة Cloudflare: من القائمة الجانبية **Storage & Databases** ← **D1 SQL Database** ← **Create Database**.
2. الاسم: `rasf-events` ← **Create**.
3. انسخ **Database ID** (رقم طويل بشكل `xxxxxxxx-xxxx-...`).

### ٣) ضع رقم قاعدة البيانات في ملف الإعداد
1. في GitHub افتح الملف `wrangler.jsonc` واضغط أيقونة القلم ✏️.
2. استبدل `00000000-0000-0000-0000-000000000000` بالرقم اللي نسخته (خلّ علامات التنصيص كما هي).
3. **Commit changes**.

### ٤) اربط GitHub مع Cloudflare
1. في لوحة Cloudflare: **Workers & Pages** ← **Create** ← **Import a repository** (أو **Connect to Git**).
2. اختر حساب GitHub والمستودع `rasf-events`.
3. في الإعدادات:
   - **Project name**: `rasf-events`
   - **Build command**: اتركه فاضي.
   - **Deploy command**: `npx wrangler d1 migrations apply DB --remote && npx wrangler deploy`
4. اضغط **Create and deploy** وانتظر لين يكتمل (دقيقة أو دقيقتين).

> ملاحظة: المنصة تنشئ جداول قاعدة البيانات تلقائيًا أول مرة تُفتح، فلو فشل جزء `migrations` لأي سبب، تقدر تخلّي أمر النشر `npx wrangler deploy` فقط وبتشتغل.

### ٥) أضف المفتاحين السريّين
1. افتح الـ Worker `rasf-events` ← **Settings** ← **Variables and Secrets** ← **Add**.
2. أضف اثنين، ونوع كل واحد **Secret** (مشفّر):
   - الاسم `SETUP_KEY` والقيمة مفتاح الإعداد اللي اخترته.
   - الاسم `SESSION_SECRET` والقيمة النص العشوائي الطويل.
3. **Deploy** / **Save**.

### ٦) افتح المنصة
رابط المنصة يظهر في صفحة الـ Worker، بالشكل:
`https://rasf-events.<اسم-حسابك>.workers.dev`

أي تعديل ترفعه على GitHub لاحقًا ينشره Cloudflare تلقائيًا.

## الطريقة (ب) — من أي كمبيوتر فيه Node.js (بالأوامر)

ثبّت Node.js (نسخة 20 أو أحدث) من <https://nodejs.org>، ثم افتح الطرفية (Terminal) داخل مجلد المشروع ونفّذ بالترتيب:

```bash
npm install
npx wrangler login
npx wrangler d1 create rasf-events
```

١. الأمر الأخير يطبع `database_id`. انسخه والصقه في `wrangler.jsonc` مكان الأصفار.

```bash
npx wrangler d1 migrations apply DB --remote
npx wrangler secret put SETUP_KEY
npx wrangler secret put SESSION_SECRET
npx wrangler deploy
```

٢. أمرا `secret put` يطلبان منك كتابة القيمة (لن تظهر على الشاشة وأنت تكتبها).
٣. أمر `deploy` يطبع رابط المنصة `https://rasf-events.<حسابك>.workers.dev`.

## بعد النشر: التشغيل لأول مرة

1. افتح `https://<رابط-المنصة>/setup`
2. اكتب **مفتاح الإعداد** واسمك وإيميلك وكلمة مرور (٨ أحرف أو أكثر) ← **إنشاء الحساب والدخول**. هذا حساب **مالك المنصة**.
   > صفحة `/setup` تتعطل تلقائيًا بعد إنشاء أول حساب، فما أحد يقدر يستخدمها بعدك.
3. **أضف الأستاذ علي كمدير**: الإدارة ← تبويب **الصلاحيات** ← «حسابات الإدارة»: اكتب اسمه وإيميله وكلمة مرور مؤقتة ← **+ إضافة مدير**. أرسل له الإيميل وكلمة المرور المؤقتة بطريقة آمنة؛ يطلب منه النظام تغييرها أول ما يدخل من `/admin`.
4. **أضف الشاشات**: تبويب **الإدارة** ← «مجموعات العرض» (مثل: الاستقبال) ثم «شاشات العرض» ← **+ شاشة**.
5. **ركّب الشاشات برابط واحد**: افتح على كل شاشة LG الرابط نفسه `https://<رابط-المنصة>/tv` (التفاصيل في القسم التالي).
6. **أنشئ مسابقة وأسئلة** ← فعّلها ← اضغط **اعرضه الآن** على السؤال. الموظفون يمسحون رمز QR الظاهر على الشاشات ويشاركون.

### ربط الشاشات برابط واحد

بدل ما تكتب رابطًا مختلفًا على كل شاشة بالريموت، كل الشاشات تفتح **نفس الرابط**:

1. على شاشة LG افتح المتصفح واكتب: `https://<رابط-المنصة>/tv` (مرة وحدة لكل شاشة).
2. تظهر المسابقة مباشرة، وفي زاوية الشريط العلوي **«رمز ربط الشاشة»** من ٤ أرقام (مثل `4821`).
3. من جوالك أو الكمبيوتر: الإدارة ← «شاشات العرض» ← اضغط **«ربط شاشة بالرمز»** بجانب اسم الشاشة، اكتب الرمز، ثم **ربط**.
4. خلال ثوانٍ تتحول الشاشة لمحتواها (المسابقة أو الصورة)، ويختفي الرمز، وتظهر «متصلة الآن» في لوحة الإدارة.

- الشاشة **تتذكر** ربطها حتى لو انطفأت أو أُعيد تحميل الصفحة.
- الرمز صالح ١٥ دقيقة، وبعدها يتجدد تلقائيًا على الشاشة.
- **لفك الربط** أو نقل الجهاز لشاشة ثانية: اضغط **«رابط جديد»** بجانب اسم الشاشة؛ يظهر على الجهاز رمز جديد فتربطه من جديد.
- قبل الربط تعرض الشاشة المسابقة ورمز QR فقط، ولا تقبل الإجابة باللمس (المشاركة من الجوال). بعد الربط تشتغل المشاركة باللمس كالمعتاد.
- الرابط الخاص لكل شاشة (`.../screen/xxxxxxxxxxxx`) ما زال يعمل كخيار متقدم.

### من يقدر يسوي إيش؟
| الدور | الدخول | الصلاحيات |
|---|---|---|
| مالك المنصة | إيميل + كلمة مرور | كل شيء، ومنها **هوية الشركة** (الشعار والألوان) و**إضافة/حذف المديرين** |
| مدير | إيميل + كلمة مرور (يضيفه المالك) | المسابقات، الأسئلة، الجدولة، الشاشات، الفعاليات، الصور، الرسائل، التحليلات، Excel |
| موظف | بدون حساب: يمسح QR ويكتب اسمه | المشاركة، إرسال رسالة للشاشة، النتائج، «حسابي» |
| شاشة LG | رابط سري لكل شاشة | عرض المسابقة/الصورة، ومشاركة الزوار باللمس |

الصلاحيات محمية من الخادم نفسه، يعني ما ينفع أحد يتجاوزها من المتصفح.

## حدود الخطة المجانية (بكلام بسيط)

- **Workers المجاني**: حوالي **١٠٠ ألف طلب يوميًا** للخادم. فتح الصفحات والصور الثابتة (التصميم والشعار) ما ينحسب ضمنها.
- **D1 المجاني**: مساحة **٥ جيجابايت**، مع حد يومي لعدد العمليات على قاعدة البيانات، وهو كافي جدًا لاستخدام داخلي.
- إذا وصلت للحد في يوم معيّن، الخدمة تتوقف مؤقتًا لين يتجدد الحد اليوم اللي بعده — **ما ينخصم منك أي مبلغ** لأنك ما أدخلت بطاقة.

**كيف نحسبها تقريبًا؟** كل جوال مفتوح على المنصة يسأل الخادم كل ٨ ثواني (≈ ٤٥٠ طلب بالساعة)، وكل شاشة كل ٥ ثواني (≈ ٧٢٠ طلب بالساعة). مثال: ٥٠ جوال لمدة ساعة + ٤ شاشات طول ١٠ ساعات ≈ ٢٢٥٠٠ + ٢٩٠٠٠ ≈ ٥٢ ألف طلب. الجوال اللي يقفل الشاشة أو يطلع من الصفحة يوقف الطلبات تلقائيًا.

**إذا احتجت تقلل الاستهلاك**: افتح الملف `public/config.js` وكبّر الأرقام (بالملّي ثانية):
```js
screenPollMs: 5000,   // الشاشات: كل ٥ ثواني  ← مثلاً 10000
phonePollMs: 8000,    // الجوالات: كل ٨ ثواني ← مثلاً 15000
adminPollMs: 10000,   // لوحة الإدارة
heartbeatMs: 60000,   // إشارة «متصلة الآن» من الشاشات
```
ثم ارفع الملف على GitHub (الطريقة أ) أو نفّذ `npx wrangler deploy` (الطريقة ب).

## ملاحظات مهمة

- **الصور فقط** في مكتبة الصور (JPG/PNG/WebP/GIF). المنصة تصغّر الصورة تلقائيًا في المتصفح لحد ١٠٨٠×١٩٢٠ وتضغطها؛ إذا بقيت أكبر من ١٫٥ ميجابايت ترفضها. **الفيديو غير مدعوم** لأن قاعدة البيانات المجانية لا تناسب الملفات الكبيرة. أنسب مقاس للشاشة الطولية: ١٠٨٠×١٩٢٠.
- **التحديث ليس لحظيًا 100%**: الشاشات تلتقط التغيير خلال ٥ ثواني تقريبًا، والجوالات خلال ٨ ثواني.
- **التصحيح يتم في الخادم**: الإجابة الصحيحة ما تُرسل للجوال إلا بعد ما ينهي الموظف محاولاته. ١٠٠ نقطة لكل إجابة صحيحة، وعند التعادل يتقدّم الأسبق.
- **حساب الموظف محفوظ على جواله** (ملف تعريف آمن داخل المتصفح). لو مسح بيانات المتصفح أو غيّر الجوال، يكتب اسمه من جديد ويبدأ سجل جديد.
- **الرابط** يكون على نطاق `workers.dev` مجانًا. لو حبيتوا لاحقًا نطاق خاص (مثل `events.rasf.sa`) يتطلب أن يكون النطاق مُدارًا في Cloudflare.
- **التصدير إلى Excel** من تبويب «التحليلات»: ثلاث أوراق (النتائج، الإجابات، الأسئلة) بتواريخ ميلادية واتجاه من اليمين لليسار.
- **نسيت كلمة مرور المالك؟** ما فيه استعادة بالإيميل (لأنها خدمة مدفوعة). الحل: من لوحة D1 في Cloudflare ← **Console** نفّذ `DELETE FROM staff WHERE role='owner';` ثم افتح `/setup` من جديد بمفتاح الإعداد. (حسابات المديرين يعيد تعيينها المالك من تبويب الصلاحيات.)

## للمطوّرين (اختياري)

```bash
npm install
cp .dev.vars.example .dev.vars          # قيم تجريبية محلية
npm run db:local                        # إنشاء الجداول محليًا
npm run dev                             # http://localhost:8787
npm run typecheck                       # فحص TypeScript
python3 tests/e2e.py                    # اختبار شامل (Playwright) على قاعدة بيانات فاضية
./scripts/reset-local-db.sh             # مسح قاعدة البيانات المحلية فقط
```

| المسار | الوصف |
|---|---|
| `src/index.ts` | الموجّه، حماية CSRF، ترويسات الأمان |
| `src/auth.ts` | حسابات الإدارة (PBKDF2)، الجلسات، رمز الموظف |
| `src/api.ts` | المسابقات، التصحيح، الشاشات، الصور، الرسائل، التحليلات |
| `migrations/0001_init.sql` | جداول قاعدة البيانات |
| `migrations/0002_tv_pairing.sql` | جدول ربط الشاشات بالرمز (`/tv`)، يُطبَّق تلقائيًا على القاعدة الموجودة |
| `public/` | الواجهة (HTML/CSS/JS) ومكتبتا QR و Excel محليًا |
| `public/config.js` | فترات التحديث |
| `public/_headers` | سياسة أمان المحتوى للصفحات |

المكتبات المضمّنة: `qrcode-generator` (MIT) و SheetJS `xlsx` 0.18.5 (Apache-2.0). الخط IBM Plex Sans Arabic من Google Fonts.
